==============================================================================
   ZFOUND - EASY INSTALLATION GUIDE FOR OTHER PCS
==============================================================================

To run ZFound on any other Windows PC, follow these 3 simple steps:

------------------------------------------------------------------------------
STEP 1: INSTALL PYTHON (If the PC doesn't already have it)
------------------------------------------------------------------------------
1. Download Python (version 3.10, 3.11, 3.12, or 3.13) from:
   https://www.python.org/downloads/

2. When installing, YOU MUST CHECK THIS BOX at the bottom:
   [X] "Add python.exe to PATH"

------------------------------------------------------------------------------
STEP 2: RUN THE 1-CLICK INSTALLER
------------------------------------------------------------------------------
1. Double-click the file:
   install_zfound.bat

2. Wait a couple of minutes while it automatically installs all dependencies.

------------------------------------------------------------------------------
STEP 3: LAUNCH THE APP
------------------------------------------------------------------------------
Whenever you want to use the application, simply double-click:
   run_zfound.bat
==============================================================================
